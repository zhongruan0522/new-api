🔓 No Authentication Required (OAuth Callback)

The actual runtime route is handled by the generic `GET /api/oauth/{provider}` endpoint, with `provider=linuxdo` here. You must provide the `state` generated by `GET /api/oauth/state` and stored in the same session, together with the `code` returned by LinuxDO. The current project only registers two providers: `github` and `linuxdo`.
